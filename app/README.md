# SvelteKit frontend

This package is the server-rendered SvelteKit 2 and Svelte 5 frontend. From `app/`, run `bun install` and `bun run dev` to start it. It currently uses starter pages and does not call the Phoenix backend.

See the [boilerplate guide](../BOILERPLATE.md) for the complete frontend command list, existing UI and localization setup, quality checks, and optional SEO work.
