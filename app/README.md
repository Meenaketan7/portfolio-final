# SvelteKit frontend

This package is the server-rendered SvelteKit 3 and Svelte 5 frontend. From `app/`, run `bun install` and `bun run dev` to start it. It currently uses starter pages and does not call the Phoenix backend.

The frontend uses Vite 8 and supported TypeScript 6. Framework configuration lives in `vite.config.ts`; `#lib` package imports resolve to the existing `src/lib/` folder.

See the [boilerplate guide](../BOILERPLATE.md) for the complete frontend command list, existing UI and localization setup, quality checks, and optional SEO work.
